# ハンドメイド作家向け「商品説明文プロンプト集」+「ショップバナー設計図」v1

## この制作物の立場について

作ったのはカズマ(40代・会社員・ハンドメイド作家ではない)です。minne・BASE・Creemaで実際に出品した経験はありません。

なので「作家目線でこう書けば売れる」という角度では作っていません。やったのは、商品説明文でよくある悩み(こだわりが言葉にならない、ギフト訴求が抽象的になる、サイズ感が伝わらない、など)を仮の商品データで想定し、プロンプトを書いて、実際にAIに生成させて、狙った出力になるかを1つずつ確認する作業です。

うまくいかなかったプロンプトは、うまくいかなかった理由と一緒に残しています。全部が一発で決まったわけではありません。

## プロンプト1: 素材・製法のこだわりを言語化する

こだわりはあるのに「丁寧に作りました」としか書けない、という悩みに向けたプロンプトです。

**プロンプト本文**
```
あなたはハンドメイド作品の商品説明文を書くアシスタントです。
以下の情報だけを使って、誇張せずに150〜200字程度の商品説明文を書いてください。
書かれていない事実を追加してはいけません。

【商品名】
【素材】
【製法・工程で工夫している点】
【完成までにかかる目安時間】
【購入者に伝えたい一言】

出力ルール:
- 一人称は使わず、屋号または「当店」を使う
- 数値・固有名詞は入力にあるものだけを使う
- 入力に「お手入れ方法」があれば最後に1文添える
```

**入力例**(本つげ櫛)
- 商品名: 本つげ櫛
- 素材: 鹿児島県産本つげ
- 工程: 伐採後の木材を3年ほど乾燥させてから彫り出し、椿油で仕上げる
- 目安時間: 1本仕上げるまでおよそ2週間
- 伝えたい一言: 使うほど艶が増す

**生成結果**
> 手作業で仕上げた本つげ櫛です。素材は鹿児島県産の本つげを使用しています。伐採後の木材を3年ほど乾燥させてから彫り出し、仕上げに椿油をなじませています。1本を彫り上げるまでにおよそ2週間かけています。使い込むほどに椿油が髪になじみ、艶が増していくのを感じていただけると思います。お手入れは、月に一度ほど椿油を数滴なじませると、艶を長く保てます。

実測171字。入力にない実績や「職人技」のような装飾語も足されず、目標に収まりました。このプロンプトは1回目で狙いどおりでした。

## プロンプト2: ギフト訴求文

「特別な日に」「大切な人へ」で終わってしまう抽象的なギフト訴求を避けるためのプロンプトです。ここは1回目で失敗し、直しました。

**1回目のプロンプト(不採用)**
```
以下の商品情報をもとに、ギフト用の商品説明文を書いてください。
【商品名】【贈り先】【シーン】
```

**1回目の生成結果(不採用)**
> 大切な人への特別な贈り物にぴったりの真鍮キーホルダーです。心のこもったギフトとして、きっと喜んでいただけるはずです。ラッピングも丁寧に対応しております。

76字。入力にあった「10文字まで刻印可能」「クラフト紙+麻紐」という具体情報が使われず、どの商品にも当てはまる文になりました。「特別な」「心のこもった」のような、何も言っていない言葉で埋まっています。これは商品説明としては使えないと判断しました。

**修正後のプロンプト(採用)**
```
以下の商品情報をもとに、ギフト用の商品説明文を100〜130字程度で書いてください。
「特別な日に」「大切な人へ」のような抽象的な言い回しは使わないでください。
入力にある固有情報(刻印文字数・ラッピング内容など)を必ず1つ以上、文中に具体的に入れてください。
値引きや在庫を煽る表現は使わないでください。

【商品名】
【想定される贈り先】
【贈るシーン】
【ラッピングの有無・内容】
【その他の仕様(刻印可否など)】
```

**入力例**(真鍮キーホルダー)
- 商品名: 刻印入り真鍮キーホルダー
- 贈り先: 結婚祝いの相手夫婦
- シーン: 新生活のスタート
- ラッピング: クラフト紙+麻紐
- 仕様: 名前の刻印は10文字まで可能

**修正後の生成結果**
> 結婚祝いに贈る、真鍮製のキーホルダーです。お二人の名前やイニシャルを10文字まで刻印できます。新しい生活で鍵を持つたびに、名前が目に入る道具になります。ラッピングはクラフト紙に麻紐を結び、そのまま渡せる形にしています。

109字。刻印文字数とラッピング内容という具体情報が入り、「特別な」のような装飾語が消えました。「固有情報を1つ以上必ず入れる」というルールを足したことが効いています。

## プロンプト3: サイズ感を体感的に伝える

数値だけ並べても大きさが伝わらない、という問題に対するプロンプトです。ここも1回目に別の問題が出ました。

**1回目のプロンプト(不採用)**
```
以下の商品のサイズ情報をもとに、実際の大きさが想像しやすい説明文を書いてください。
身近なものに例えて大きさを伝えてください。
【商品名】【サイズ】【重さ】
```

**1回目の生成結果(不採用)**
> 手のひらにすっぽり収まる、野球ボールほどの厚みがあるマグカップです。ちょうどよい大きさで、毎日のコーヒータイムにおすすめです。

「野球ボールほどの厚み」は入力に無い比較で、AIが勝手に作った表現でした。マグカップの厚みを野球ボールに例えるのも、正直あまり実感が湧きません。実在しない事実を書かせてしまった例です。

**修正後のプロンプト(採用)**
```
以下の商品のサイズ情報をもとに、実際の大きさが想像しやすい説明文を80〜100字程度で書いてください。
比較対象は【比較対象】の欄にあるものだけを使ってください。
比較対象が空欄の場合は、例えを作らず数値のみで正確に書いてください。

【商品名】
【サイズ(縦横高さ/直径など)】
【重さ】
【比較対象】(あれば)
```

**入力例**(陶器のマグカップ)
- 商品名: 陶器のマグカップ
- サイズ: 直径8.5cm×高さ9cm
- 重さ: 約230g
- 比較対象: 缶コーヒー1本分より少し重いくらい

**修正後の生成結果**
> 直径8.5cm、高さ9cmの陶器のマグカップです。重さは約230gで、缶コーヒー1本分より少し重いくらいです。普段づかいのマグとして、程よい持ちごたえがあります。

81字。比較対象を入力側で用意させ、無ければ作らせない、という制約を入れたことで、ありもしない例えが消えました。作家自身が「これくらいの重さ」と実感を持っている対象を書いてもらうのが前提になるプロンプトです。

## プロンプト4: 季節限定商品の紹介文

期間限定商品を煽らずに紹介するためのプロンプトです。ここでは文字数の目標設定そのものに問題がありました。

**プロンプト本文**
```
以下の情報をもとに、季節限定商品の紹介文を100〜140字程度で書いてください。
「今だけ」「売り切れ次第終了」のような焦らせる表現は使わないでください。
季節感は、入力にある素材・色・モチーフの具体だけで伝えてください。
入力にない特徴(サイズ・用途など)を付け足さないでください。
情報が少なく字数に届かない場合は、無理に埋めず短くまとめてください。

【商品名】
【販売期間】
【季節を感じさせる素材・色・モチーフ】
【通常商品との違い】
```

**入力例**(ちりめん細工の髪飾り)
- 商品名: 紅葉ちりめん細工の髪飾り
- 販売期間: 10月〜11月末
- 素材・色: 柿渋色と山吹色のちりめん生地、紅葉した葉の形
- 通常品との違い: 通常のちりめん細工は白ベースだが、この時期だけ柿渋・山吹の生地を使う

**生成結果**
> 柿渋色と山吹色のちりめん生地で、紅葉した葉の形に仕立てた髪飾りです。10月から11月末までの期間限定でつくっています。ふだんのちりめん細工は白い生地をベースにしていますが、この時期だけ柿渋色と山吹色の生地を使っています。

110字。目標を140字にしても、この量の入力情報では110字あたりで自然に止まります。

最初、この目標を240〜280字に設定していました。その字数を守らせようとすると、「着物や浴衣にも」のような、入力に無い使用シーンをAIが付け足してくる場面がありました。字数目標を高く設定しすぎると、事実にない情報で埋めようとする傾向がある、というのがプロンプト3・4を通しての発見です。目標字数は、入力情報の量に対して現実的な範囲に収めるべきだと分かりました。

## プロンプト5: お手入れ・使用上の注意

「デリケートな素材なので優しく扱ってください」のような曖昧な注意書きを、具体的な行動に落とすプロンプトです。

**プロンプト本文**
```
以下の情報をもとに、購入後の安心材料になるお手入れ・使用上の説明を80〜120字程度で書いてください。
「優しく扱う」「デリケートなので」のような曖昧な表現ではなく、
入力にある具体的な行動(触れさせない物・避ける状況・お手入れの手順)だけで書いてください。

【商品名】
【素材】
【避けてほしい使い方】
【お手入れ方法】
```

**入力例**(真鍮ピアス)
- 商品名: 真鍮アクセサリー(ピアス)
- 素材: 真鍮に透明コーティング
- 避けてほしい使い方: 香水・ハンドクリームを直接つけない/汗をかいたまま長時間つけない
- お手入れ方法: 柔らかい布で乾拭き

**生成結果**
> 真鍮に透明のコーティングをした素材です。香水やハンドクリームが直接つくと、変色が早まることがあります。汗をかいたまま長時間つけるのも変色の原因になるので、外したあとは柔らかい布で乾拭きしてください。

99字。「変色の原因になる行動」が具体的に並び、抽象的な注意書きにならずに済みました。1回目でそのまま使える結果でした。

## プロンプト6: ショップ紹介文(ブランドストーリー)

BASEのようにショップ全体のトップに置く自己紹介文です。実績の捏造を防ぐ制約を、プロンプトの中に明記しています。

**プロンプト本文**
```
作家自身のショップ紹介文を180〜260字程度で書いてください。
実績・資格・受賞歴・販売実績は、入力に明記されているものだけを使ってください。
入力に書かれていない実績は、絶対に書き加えないでください。
「作り始めたきっかけ」と「作るときに大事にしていること」の2点を中心に構成してください。

【屋号】
【作り始めたきっかけ】
【作るときに大事にしていること】
```

**入力例**(刺し子ブランド)
- 屋号: fukurou工房
- きっかけ: 祖母の裁縫箱を譲り受けたのがきっかけで刺し子を始めた
- 大事にしていること: 一枚の布を最後まで無駄にしないこと/生活の中で使える大きさ・厚みにすること

**生成結果**
> fukurou工房は、祖母から譲り受けた裁縫箱をきっかけに始めた刺し子のお店です。譲り受けた裁縫箱には、使いかけの糸や古い布が入っていて、それを見ているうちに、自分でも刺してみたいと思うようになりました。作るときに大事にしているのは、一枚の布を最後まで無駄にしないことです。端切れになった部分も、小さな作品に仕立てています。もうひとつ大事にしているのは、生活の中で実際に使える大きさや厚みにすることです。飾るだけでなく、使ってもらえるものを作っています。

実測227字で、260字の上限には届くものの下限180字はぎりぎりでした。「〇〇コンテスト受賞」のような実績を勝手に足すことはなく、入力の2項目だけで構成されています。ここは実績を捏造させないための制約(「書かれていない実績は書き加えない」)が効いているかを確認するのが主目的のプロンプトで、その点は狙いどおりでした。

## プロンプト7: 色・サイズ違いをまとめて出す

同じ商品でバリエーションがある場合、基本説明とバリエーションの違いを分けて出すプロンプトです。

**プロンプト本文**
```
同じ商品で複数のバリエーション(色・サイズなど)がある場合の説明文を書いてください。
基本説明を60〜90字程度、バリエーションごとの違いを1行ずつの箇条書きで書いてください。
バリエーションの数は入力に与えられた数だけにし、入力に無い色・サイズを作らないでください。

【商品名】
【共通の説明(素材・用途など)】
【バリエーション一覧】
```

**入力例**(はぎれのミニポーチ)
- 商品名: はぎれのミニポーチ
- 共通説明: 木綿はぎれを使ったミニポーチ、内側に防水生地
- バリエーション: ①藍染柄(一点もの) ②生成り×水玉(在庫3点) ③からし色無地(在庫5点)

**生成結果**
> 木綿のはぎれを使ったミニポーチです。内側には防水生地を使っているので、濡れてもいいものを入れるのに使いやすいと思います。
> - 藍染柄:一点ものです
> - 生成り×水玉:在庫3点
> - からし色無地:在庫5点

基本説明は実測60字で下限ちょうど。入力に無い4色目・4サイズ目を作ることもなく、与えられた3種類のみで箇条書きが構成されました。

## プロンプト集全体を通しての検証メモ

- 目標字数を高く設定しすぎると、AIは字数を埋めるために入力にない情報を作る傾向がありました(プロンプト3・4)。目標字数は「入力情報の量から現実的に届く範囲」に合わせるべきです。
- 「入力にない情報を書き加えない」というルールは、プロンプトに明記しないと守られないわけではありませんが、明記した方が事故は減ります(プロンプト2・3・6)。
- 「特別な」「効果的な」のような装飾語だけの文は、制約を与えずに生成すると出てきやすいと感じました。ここは商品説明文に限らず、AI生成文全般で言われている傾向と近いと思います。

## Canvaテンプレート設計図(ショップバナー用)

実際のCanva編集ファイルは作れないため、Canva上で手動再現するための設計図として渡します。

### 前提として: プラットフォームごとの推奨サイズ

各プラットフォームのヘルプページ本体には、今回の作業環境からアクセスできず(egressの制約で直接確認できませんでした)、検索結果に基づく間接的な情報です。投稿前に必ず各サービスのヘルプページで最新の推奨サイズを確認してください。

- minne: ショップカバー画像は1100×280px以上が目安、とする情報がありました。
- BASE: ショップの背景・ロゴ画像には明確な推奨サイズの指定は無く、「4500×4500px以内・1MB以下」で試してアップロード後に確認する運用、とする情報がありました。スライドショー画像は正方形900×900pxが目安、とする情報もありました。
- Creema: ショップカバー画像は851×315pxが目安、とする情報がありました。

サイズがプラットフォームごとに異なるため、テンプレートは「1500×1500pxの正方形」を親データとして作り、そこから各サイズにトリミングする構成にします。この作り方なら、サイズ変更のたびに作り直す必要がありません。

### レイアウト構成案(3パターン)

**パターンA: シンプル型(通年で使う基本バナー)**
- 左1/3: 屋号ロゴまたは屋号テキスト(見出し級のフォントサイズ)
- 中央〜右2/3: 代表作品の写真1枚(全体の主役)
- 下部に細い帯: キャッチコピー1行(10〜16文字程度)
- 余白: 上下左右とも、トリミングで切れても文字が欠けないよう、外周10%は文字・ロゴを置かない「セーフエリア」にする

**パターンB: 季節訴求型(期間限定商品の告知用)**
- 背景: 季節を感じさせる単色または淡いグラデーション(商品の色から1色を抽出して使う)
- 中央: 商品写真を丸or角丸フレームで配置
- 商品写真の右または左: 「期間: 10/1-11/30」のような販売期間の一文(煽り文句を避け、期間だけを事実として書く)
- ロゴは端に小さく配置(主役は商品写真)

**パターンC: 複数商品訴求型(バリエーション商品・まとめ買い訴求用)**
- 上部帯: 屋号
- 中央: 商品写真を2〜3枚、均等な間隔でグリッド配置(3枚を超えると窮屈になりやすいので、代表色違い2〜3点にとどめる)
- 下部帯: 「全〇色展開」のような、入力データにある事実のみのテキスト

### 配色案(3パレット)

- 素朴・ナチュラル系(木工・陶芸・刺し子向け): ベージュ #E8DFD3 / 深い茶 #6B4A32 / 差し色の柿渋色 #B4602A
- 華やか・アクセサリー系(真鍮・天然石向け): 生成り #F5F0E8 / 黒に近いネイビー #24262B / 差し色のゴールド #B08D57
- 季節限定・訴求強め系(期間限定商品向け): 白 #FFFFFF / 差し色1(素材の色に合わせて変更) / 差し色2(差し色1の補色に近い色、彩度を落として使う)

配色は「ベース1色+差し色1〜2色」の3色以内にとどめる設計にしています。色を増やすほど、Canva公式テンプレートとの違いが分かりにくくなるためです。

### Canvaでの再現手順

1. Canvaで「カスタムサイズ」を選び、1500×1500pxの正方形で作成する
2. 上記レイアウト案をもとに、テキストボックス・画像枠・図形(帯や丸枠)を配置する
3. 配色案の3色を「カラーパレットを保存」機能で登録し、テンプレート内の全要素をその3色に統一する
4. フォントは見出し用と本文用の2種類に絞る(Canva内の日本語フォントは「みんなの文字」「はんなり明朝」など、商品の雰囲気に合わせて選ぶ)
5. 完成したデータを、minne/BASE/Creemaそれぞれの推奨サイズに合わせて「サイズを変更」機能で複製し、はみ出す部分が無いかセーフエリアを確認してから書き出す
